mado ML Trackingの初回リリースです。実験の比較、モデル・コード・データセットのバージョン管理、学習・推論・評価の実行を同じアプリで扱います。

## 主な機能

- Runのパラメータ・メトリクス・ログ・音声や画像の記録と比較
- モデル・コード・データセットの固定バージョン、生成元Run、加工元の来歴
- SSH workerによる学習・推論・評価、サイトへのJob投入、コード編集と前処理ワークフロー
- モデル登録後の自動推論・評価、探索実験、再開、共有レポート
- Python SDKとMLflow 3互換API、ファイルシステム・S3互換ストレージへの保存
- ローカルアカウント・OIDCによるログイン、Projectごとの権限、API token、監査ログ
- 標準搭載のmado S3 Data Catalog連携（初期状態は無効）、日本語・英語の画面とドキュメント

## 配布物と導入

Linux amd64/arm64向けに、Web、API、プレビュー用worker、実行worker、サイトlauncherの5種類をGHCRで配布します。イメージ名は`ghcr.io/aida0710/mado-ml-tracking-{web,api,preview,worker,launcher}:v0.1.0`です。

添付の`mado-ml-tracking-v0.1.0.tar.gz`には、イメージをdigestで固定したCompose、設定例、初回起動の手順、worker・launcherの設定例が入っています。ソースのビルドは不要です。SHA-256のチェックサムとビルド証明も添付します。

展開した配布物のREADMEに従って設定とDB更新、初期管理者の作成を行ってください。[ドキュメント](https://aida0710.github.io/mado-ml-tracking/)には機能、SDKでの記録、実行環境の登録手順があります。

## 初期リリースでの制限

HTTPSの入口と、実行するコンピュータ・SSH鍵・ストレージは利用者の環境で用意します。GPU用の学習イメージはこの配布物に含めません。Mado連携を使う場合は、Data Catalog側の参照APIと互換Dataset Registryを設定してください。

MLflow 3互換APIの対応範囲は[MLflowの手順](https://aida0710.github.io/mado-ml-tracking/tracking/mlflow)を参照してください。モデルの配信、MLflowのTracing・GenAI・Gateway・Prompt Registryは対象外です。
